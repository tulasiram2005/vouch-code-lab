# Hosting and operating costs

The connected Netlify team reported the Free plan on 21 November 2026. No paid upgrade, AI API, metered inference service or commercial UI kit is required. Each new browser downloads the self-hosted Python runtime when it starts the runner, so bandwidth matters. Cacheable assets can be reused on later runs.

Netlify currently documents 300 monthly credits with a hard cap on its credit-based Free plan. Older accounts may have legacy terms. The dashboard identifies the actual team plan. Managed Netlify Database requires a credit-based plan, and its compute and traffic use the same included allowance.
